Development journey

xSAR is being built in stages. This page records what is current, what has been completed and what comes next. Dates are included so visitors can see both the history and the present pulse of the project.

Current focus · July 2026

CAN FD communications

Bench testing isolated USB analysers and SPI CAN FD modules for communication between sensor nodes and flight-control systems.

Sensor acquisition

Comparing analogue acquisition paths, validating channel consistency and preparing longer datasets for trend analysis.

Embedded Rust

Preparing RP2350 firmware structure and shared crates for sensing, control and communications nodes.

Recent milestones

29 July 2026 · Website and repository structure

Separated the public development journey from the open-source repository map, added clear project links and made support and current activity easier to find.

July 2026 · Public repository map

Organised the GitHub profile by engineering area, including firmware, sensors, positioning, DSP, Linux tools, Rust crates and inter-device communications.

July 2026 · Sensor logger version 2 planning

Defined grouped, oscilloscope-style channel views, central parameters and cleaner separation between collection, configuration and display.

Next steps

  • Define and document the CAN FD message structure.
  • Publish initial RP2350 firmware scaffolding when interfaces are stable enough to be useful.
  • Add photographs, plots and test summaries to dated progress entries.
  • Continue moving mature tools from offline development into public repositories.

Follow shorter updates

Day-to-day engineering notes, hardware arrivals and smaller milestones are shared on X @xSAR_Research. Public code and documentation live on the Open Source page.
