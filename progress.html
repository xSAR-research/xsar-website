Progress

xSAR is on an open-source journey. We are moving our code under the GNU Affero General Public License version 3.0 (AGPL-3.0) so that research, field experiments and improvements stay available to the communities that need them. Publishing under a strong copyleft licence keeps the work free to study and adapt while ensuring that changes made for real deployments can flow back to everyone building quieter support for emergency services and the State Emergency Service (SES).

Our target is practical kit for the edge: embedded firmware that can live on small devices in the field, and useful Linux tools written mainly in Rust and Python for reliable automation, sensing and mesh-aware workflows. Progress is measured in working software and honest documentation—not slide decks. As repositories mature, they appear under the public organisation so others can follow along, file issues, and reuse what helps rescuers on the ground.
